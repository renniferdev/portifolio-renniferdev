# ⚠️ INSTRUÇÕES PARA O QODO

## 🚫 NÃO CRIAR

- ❌ Arquivos `.md` descritivos
- ❌ Arquivos `.txt` explicativos
- ❌ Arquivos de documentação
- ❌ Guias de como fazer algo
- ❌ Status reports
- ❌ Checklists
- ❌ Troubleshooting guides

## ✅ CRIAR APENAS

- ✅ Código que resolve o problema
- ✅ Arquivos de configuração (`.env`, `.json`, etc)
- ✅ Scripts executáveis (`.ps1`, `.js`, `.py`, etc)
- ✅ Modificações em arquivos existentes

## 💰 RAZÃO

Arquivos descritivos gastam créditos do Qodo sem resolver nada. Foco em **AÇÃO**, não em **DESCRIÇÃO**.

## 🎯 QUANDO RECEBER TAREFAS

1. **Analisar o problema** usando as ferramentas
2. **Executar ações** que resolvem
3. **Testar** se funcionou
4. **Reportar resultado** em texto simples (sem arquivo)

## 📝 EXEMPLO ERRADO

```
Criar: SOLUCAO_CONEXAO_VERCEL.md (❌ ERRADO)
Criar: TESTE_BACKEND.md (❌ ERRADO)
Criar: STATUS_ATUAL.md (❌ ERRADO)
```

## 📝 EXEMPLO CORRETO

```
Modificar: backend/api/send-email.js (✅ CORRETO)
Modificar: backend/vercel.json (✅ CORRETO)
Executar: npm install (✅ CORRETO)
Testar: curl https://... (✅ CORRETO)
```

## 🔥 RESUMO

**CÓDIGO > DOCUMENTAÇÃO**

Resolve o problema. Pronto.
